# Uhnder

> Uhnder, Inc. is an Austin, Texas fabless semiconductor company founded in 2015 that
> designs 77 GHz 4D digital imaging Radar-on-Chip (RoC) devices for automotive ADAS and
> automated mobility. Its Digital Code Modulation (DCM) approach on a 28nm RF CMOS process
> replaces analog FMCW radar with a software-defined sensor. Each RoC ships with an
> ASPICE-qualified SDK carrying ready-to-integrate software APIs, on-chip user-algorithm
> support and system tools for Tier-1 and OEM radar stacks.

Uhnder is a chip supplier, not a web-API provider. As of 2026-08-05 it publishes no public
developer portal, no documentation host, no machine-readable API contract (OpenAPI, AsyncAPI,
GraphQL, MCP, A2A), no SDK packages on any public registry, and no public source repositories.
The SDK and its APIs are embedded interfaces delivered to automotive customers under a
commercial relationship; the only public entry point is the contact address below.

## Products

- [S80 77 GHz Digital Radar-on-Chip](https://www.uhnder.com/products/): fully software-defined 4D imaging RoC — 12 Tx and 2x8 Rx antenna channels, 96 VRx with True MIMO, software-defined frame and scan configuration, on-chip user algorithms
- [S81 77 GHz Digital Radar-on-Chip for Mass Market](https://www.uhnder.com/products/): lower-cost 4D imaging RoC with DCM, multichip cascading, hack-resistant to radar spoofing
- [S80 Product Technical Brief (PDF, v2.0, April 2024)](https://www.uhnder.com/images/data/S80_PTB_v2.0_1_.pdf)
- [S81 Product Technical Brief (PDF, v1.0, April 2024)](https://www.uhnder.com/images/data/S81_PTB_v1.0_(1)_.pdf)

## Software surface

- ASPICE-qualified Software Development Kit with ready-to-integrate software APIs (stated in the S80 and S81 Product Technical Briefs)
- Production-ready software, algorithms and system tools shipped with the RoC
- On-chip user algorithm execution on the integrated CPU and DSP cores
- Chip I/O interfaces: 3 x 100/1000 Ethernet, 2 x CAN-FD, 2 x I2C, QSPI, GPIO
- Access: commercial customer relationship only — no public download, registration or documentation host
